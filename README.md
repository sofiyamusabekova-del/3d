# Планировщик квартиры

Редактор квартиры для ремонта: 2D-план и 3D, мебель из каталога, отделка стен, время суток и вид за окнами, «Качественный снимок». Документы: `docs/PRD-interior-planner.md`, `docs/SPEC.md`, `docs/Tasks.md`, `docs/PLAN.md`, отчёт приёмки `docs/reports/stage19.md`.

## Требования

Node.js 20+ (проверено на 24.21), npm 11, установленные Chrome и Edge (для e2e). Для 3D нужен браузер с WebGL2; для «Качественного снимка» ещё и расширение `EXT_color_buffer_float`.

## Запуск

```
npm install        # зависимости (есть package-lock.json)
npm run dev        # запуск, http://localhost:5173
```

Порядок работы в приложении: число комнат, площадь, схема, настройка геометрии, интерьер. На шаге «Интерьер» слева панели (комнаты, двери, отделка стен, каталог), в центре план, справа 3D с ползунком времени суток и кнопкой «Качественный снимок».

## Проверки

```
npm run typecheck  # проверка типов
npm test           # модульные тесты (Vitest)
npm run test:e2e   # браузерные тесты (Playwright, Chrome и Edge)
npm run build      # сборка
```

Замеры скорости по порогам SPEC D-08 запускаются отдельно (результат в `docs/reports/stage18/`):

```
MEASURE=1 npx playwright test perf --workers=1
```

Если Vitest падает при старте воркера (код 0xC0000005, сбой среды), запускать с `--pool=threads`.

## Каталог мебели

Каталог (78 предметов, свет предметов — `src/catalog/lights.ts`) собирается из исходных моделей скриптами `scripts/catalog/`: перечень и решения по карточкам — `scripts/catalog/items.mjs`, сборка моделей — `build-models.mjs` (собственные модели люстр сначала строит `make-lights.mjs`), превью карточек — `previews.mjs` (нужен запущенный `npm run dev`), реестр источников и лицензий — `report.mjs`, результат в `docs/ASSETS.md`. Исходники моделей лежат в `assets-src/`. После `build-models.mjs` для веса запускается `compress-models.mjs` (сжатие геометрии meshopt, обновляет вес в манифесте); превью карточек и миниатюры обоев — WebP (`optimize-images.mjs`). Шаг «Интерьер» и 3D-движок грузятся отдельным куском только при переходе на него; замер веса и скорости загрузки — `node scripts/measure-load.mjs` (нужен `vite preview` на порту 4173), отчёт `docs/reports/stage28.md`.

## Известные ограничения

- Стартовые схемы: 9 планировок без мебели, чистая площадь 36–89 м² (1 комната 36–49, 2 комнаты 53–68, 3 комнаты 80–89 м²). Введённая площадь только подбирает ближайшую схему, размеры комнат меняются на шаге «Настройка».
- Главное меню (этапы 29–30): первый экран при каждом открытии, чёрно-белый. Слева живая 3D-комната (`src/ui/StartRoom3D.tsx`, грузится после показа меню; без WebGL или пока грузится — SVG-картинка), справа текст и кнопки: «Продолжить проект» (если есть сохранение), «Новый проект» (с подтверждением, если сохранение есть), «Открыть проект» (файл). Щелчок по подвесному плафону и шнур выключателя переключают день (13:00) и ночь (23:00): физика шнура перенесена из Pull Cord (`src/ui/pullCord.ts`), час общий с ползунком и редактором (`useInterior.hour`). Шнур доступен с клавиатуры (Enter или Пробел на переключателе), при «уменьшить движение» переход мгновенный. Проверка вручную: открыть `/`, потянуть шнур вниз и отпустить, нажать на плафон, подвигать ползунок. Для автотестов меню выключается ключом `interior-planner:skip-start` в localStorage (задан в `playwright.config.ts`, тест меню — `tests/e2e/start.spec.ts`). Картинка комнаты — SVG, не снимок 3D-движка.
- Сохранение: проект автоматически сохраняется в этом браузере (localStorage); при следующем открытии предлагается продолжить или удалить сохранение. В шапке: «Сохранить в файл» (`kvartira-ГГГГ-ММ-ДД-ЧЧММ.json`), «Открыть файл», «Новый проект». Сохраняются квартира, схема, шаг, время суток и выключатели; история отмены нет. Хранения на сервере, аккаунтов и ссылок нет. Автосохранение привязано к браузеру и адресу сайта: другой браузер или очистка данных сайта его не увидят, для переноса используйте файл.
- Комнаты только прямоугольные; перенос окна или двери на другую стену не предусмотрен.
- Предметы каталога ставятся на пол (настенных в каталоге пока нет); настольная техника (ноутбук, монитор, телевизор, радио, тостер, микроволновка) ставится только на стол, тумбу или кухонный модуль.
- Свет: в каждой комнате подвесной светильник и выключатель комнаты (кнопка «Свет» под 3D), в каталоге торшеры, настольные лампы, бра, люстры и плафон. Одновременно светят не более 6 источников. Выключатель хранится только в открытой вкладке.
- Пол: у каждой комнаты своё покрытие (ламинат с досками 19 × 120 см, линолеум, ковролин, по три цвета), панель «Пол» в интерьере, цвет виден на плане. Текстуры рисуются кодом, файлы не загружаются. Покрытие входит в проект и историю отмены.
- Бра ставится на стену (притягивается к ближайшей), люстра висит от потолка и заменяет подвесной светильник.
- Режим «Прогулка» (кнопка под 3D): вид от первого лица на высоте глаз 160 см по всей квартире. W A S D или стрелки — ходьба, Shift — быстрее, мышь с зажатой кнопкой — обзор, Esc — выход. Стены и мебель не пускают, внутренние двери проходимы, окна и входная дверь нет. Выход возвращает в ту же комнату, проект не меняется. В прогулке светят источники комнаты, где стоит игрок (не больше шести, ближайшие к нему); лампы в других комнатах только светятся, не освещая через стену. Качественный снимок в прогулке недоступен.
- Оформление: единая тёмная тема, система переменных в `src/ui/tokens.css` (цвета слоёв, текста, акцента, плана, шкала текста, радиусы, отступы, тени, фокус). Контраст текста не ниже AA, границ и графики не ниже 3:1 (проверяют `tests/unit/theme.test.ts` и `tests/e2e/theme.spec.ts`). Общие состояния кнопок и полей (наведение, нажатие, фокус клавиатуры, отключено) заданы в `src/index.css`. Светлой темы нет.
- «Качественный снимок»: первая съёмка около 1–2 минут (компиляция шейдера видеокартой), повторная в той же сессии быстрая. В снимке нет потолка, поэтому свет сверху попадает в комнату иначе, чем в редакторе.
- Лицензия 9 моделей FurniMesh не CC0 (заявление сайта: бесплатно, коммерческое использование, без указания авторства): условия перепроверить перед публикацией.
- Скиллы проекта лежат в `.claude/skills` (установлены командой `proweb-skills install ... --agent claude`).
